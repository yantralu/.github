# 🛠️ Yantralu

> **Curated Registry for Usable AI Software, CLIs, & Frameworks**

Yantralu indexes and curates functional AI software (tools, CLIs, orchestrators, and developer runtimes like Ollama, LangChain, Cursor) while strictly excluding raw weights and dataset dumps.
